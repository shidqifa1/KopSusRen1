📊 Import & Export CSV

Export data untuk diedit di Google Sheets/Excel, lalu import kembali file CSV-nya ke Kopi Manager.

📌 File hasil export boleh diedit, lalu tekan tombol import yang sesuai. Import penjualan bersifat historis dan tidak mengurangi stok hari ini; import kas akan memperbarui saldo.
🗂️ Backup Data

Unduh snapshot JSON untuk arsip atau pulihkan setting stok, threshold, harga, resep, dan saldo kas. Riwayat transaksi dipulihkan lewat import CSV agar tidak tertimpa tanpa sengaja.
